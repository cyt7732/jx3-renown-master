# 剑网3名望时间管理大师

实时追踪剑网3四大名望组织活动排班，合理安排游戏时间。

## 追踪组织

| 组织 | 循环周期 | 地图 |
|:---|:---|:---|
| 楚天社 | 2小时 | 烂柯山 → 晟江 → 百溪 → 楚州 |
| 云从社 | 2小时 | 银霜口 |
| 披风会 | 3小时 | 河西瀚漠 |
| 穹野卫 | 3小时 | 伊丽川 |

## 功能

- 实时显示各组织当前活动及未来活动排班
- 按组织筛选
- 时间范围可调（30分钟 ~ 24小时）
- 自定义测试时间
- 活动类型图标
- 每分钟自动刷新

## 使用方法

1. 将整个项目文件夹部署到 NAS / 静态服务器
2. 浏览器打开 `index.html` 即可
3. 无需后端，纯静态页面

## 数据来源

剑网3 CMS API：`cms.jx3box.com/api/cms/game/celebrity`

图标来自：`img.jx3box.com/pve/minimap/`

## 技术栈

- HTML + CSS + JavaScript（纯前端，零框架依赖）
- Font Awesome 6.4.0（CDN 图标库）
- localStorage 缓存 + 偏好持久化
