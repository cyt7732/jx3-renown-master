# 解阵求解器

剑网三「解阵」小游戏的求解工具。规则和 Flow Free 一样：**同色两端用一条线连起来，所有格子都要被覆盖，线不能交叉**。

## 用法

### 0. 剪贴板模式（最爽，推荐）

1. 游戏里按 **Win+Shift+S** 框选棋盘（图自动进剪贴板）
2. 双击桌面上的 **「解阵求解」** 快捷方式
3. 答案图自动弹出来，照着拖就行

不用存文件、不用敲命令。窗口会显示识别过程，成功后自动关闭。

### 1. 一键求解（处理文件夹里的图）

**双击 `一键求解.bat`** —— 自动挑这个文件夹里最新的截图来解。

也可以**把截图直接拖到 `一键求解.bat` 图标上**。

### 2. 网页版

双击 `index.html`，浏览器打开就能用：

- 点左边的颜色 → 点棋盘格子放端点，每个颜色放 2 个
- 点「求解」，毫秒级出答案
- **右键**格子 = 清掉这个端点
- 再点一次已选中的颜色 = 取消选色（变橡皮）
- 「载入本次题目」= 一键载入 2026-11-01 这局
- 网址后加 `?preset=1&solve=1` 可以直接打开就出解

### 3. 命令行（要自己敲）

```bash
python auto_solve.py 截图.png
```

> 注意：直接双击 `.py` 文件是没反应的（Windows 会闪一下就关，或者用记事本打开）。要么用上面的一键 bat，要么在命令行里带上截图路径。

### 4. 直接抄答案

`sample_answer.png` 是本次这局的答案，路径已经叠在截图上了。

## 文件说明

| 文件 | 用途 |

## 原理

深度优先搜索 + 可达性剪枝：

每铺一格就做一次「连通性体检」——从所有未完成颜色的端点出发做多源 BFS，如果发现有空格子谁也连不到，说明这条路已经死了，立刻回溯。这个剪枝把 7×7 的搜索量从几十万压到个位数节点。

搜索顺序按端点曼哈顿距离**从远到近**，这样解出来的线长度比较均衡，游戏里好拖（先解近的会得到一条 3 格的线和一条 28 格的线，后者极容易画错）。

## 说明

- 脚本按剑网三解阵的固定 7×7 界面识别，换尺寸需要改 `N`
- 端点颜色按色相分箱：红/橙/黄/绿/青/蓝/紫/粉
- 识别不准时（背景太花），直接用网页版手点更快
